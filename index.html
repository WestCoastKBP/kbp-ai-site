What we're working on

Our own tasks show us what works, where a person needs to decide, and what breaks in everyday use.

Tools for building software with agents

We work with agents from more than one vendor. We are testing how they receive context, use tools, hand work over and check results.

Assistants for business workflows

We use correspondence and business tasks to explore incoming messages, replies prepared for approval, and follow-ups that should not be lost.

How we work

We start from tasks we actually have. We use existing tools where they fit, then build the connections or behavior the task still needs.

Local and cloud experiments

We experiment with where agents run, how they keep context, what tools they can use and how a workflow recovers when it stops.

Open-source plans

We plan to release the parts that hold up in our own use as free, open-source tools, with setup instructions and known limitations.

One workflow we're testing

An incoming meeting request, an editable reply, and a draft that remains after reopening the application.

Read the source
Keep the original message, account and time visible. Check which day, time zone and location the sender means.
Prepare a reply
Let a person review and edit the draft before any message is sent.
Reopen and check
Check that the same message and exact draft are still there. A prepared reply is not a sent message.

This workflow is in development. It is not available as a public KBP AI integration.
